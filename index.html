Pyodide Llama2

An experiment in how far Python on WebAssembly can go: a language model that runs entirely in your browser, written in Python with NumPy on Pyodide. It is a test bed, not a product, so expect small models and odd answers.
ブラウザ上の WebAssembly 版 Python (Pyodide + NumPy) だけで言語モデルを動かす実験プロジェクトです。 実用ではなく試験が目的のため、モデルは小さく、出力はそれなりです。

About this project, its models and licenses (click to open)

Pyodide is a Python distribution for the browser and Node.js based on WebAssembly. It allows you to run Python code and use many scientific Python packages directly in your web browser.

You can run llama2.py, ported to NumPy, in Pyodide
