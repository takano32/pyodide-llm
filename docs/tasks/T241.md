- **選んだ形は (a) 尺度を NaN にする、理由**: (1) 配線が要らない。DP4A の行列（タイルの `dp4a` と `fusedDp4aMatVec` の `SDP8AI`）はグループの整数の和に 尺度 × 重みの尺度 を掛けて行の中で足すので、1 つのグループの尺度が NaN なら出力のどの行も NaN になる。残差で流れは NaN のままになり、後ろの量子化はまたビットで見つけ、分類器の logits が NaN になって T219 の印が断る。印の語を別に運ぶ形 (b) は、量子化のたびにバインドを 1 つ、State に置き場、gpu.js と forward.js に読み手が要るのに、logits がもう同じことを言っている。(2) 途中に float の max・min・clamp・select・比べが無い。NaN を運ぶのは掛け算と足し算だけで、これは T219 の印が float の形でもともと頼っているもの。(3) 無限大も NaN にする: 尺度が無限大だと行は整数の和の符号で +inf か −inf（和が 0 なら NaN）になり、−inf だけの logits は T195 の規則で断られない。(4) 尺度の語は整数の比べで選び整数で書くので、端末の float に「NaN か」を聞く所が無い。
