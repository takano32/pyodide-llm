- 向こうの `engine::repetition` の形（docs/notes/t664-… の 4）: 周期 128 まで、64 トークン以上が 3 回以上で「くり返し」、プロンプトに正当なくり返しがあれば線をその 2 倍に。出力の上限は切れ端の 3 倍 + 128。途中で終わった訳（200 以上の切れ端で 1/4 未満）も同じに扱う。立て直しは 256 トークンずつ → 文ごと → DRY（T668）→ 最初の 1 周期で切って印。くり返した訳は履歴に入れない。
