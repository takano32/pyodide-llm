### T.627 [整理][CPU] GPU に置けないモデルの `gpuBytes()` — 状態: 完了（2026-10-30、T.623 から。規模 小。調べて、直す要なしと分かった）
- `forward/alone.ts` の `gpuBytes()` は、GPU に置けないモデル（`gpuOnlyUnfit()` が断るモデル）にも Llama の行の形で GPU のバイト数を答える。`worker/weights.ts` の `gpuOnlyWeightsFor()` はそれを判定の前に数え、置けないモデルでも `weightsPlace({ cpu, gpu, deviceMemory })` の 2 重の判定に入る。直す案: 置けないモデルの GPU の数を判定に入れない（`weightsPlace()` に `gpu: 0` か、2 重を考えない道）。先に、今の数でどのモデルの置き場が変わるかを一覧の全項目で数える（`deviceMemory` 4・8 の端末で）。
- **調べた（2026-10-30、取りまとめ役の決め: 直さない）**: 置けないモデルでは数が効かない。`weightsPlace()` が返す「both」と「cpu」は、どちらも `gpuRoom` が `room - cpu` で同じ（`forward/alone.ts`）。worker（`worker/weights.ts` の `weightsBuffer()`）が道を分けるのは `mode === "gpu"` のときだけで、それには `eligible`（`gpuOnlyUnfit()` が通すこと）が要る。だから `gpuBytes()` の数が違っても、置けないモデルの置き場も `gpuRoom` も変わらない。コードは触っていない。
