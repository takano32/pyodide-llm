- **T363.5 の結果（2026-10-13、Opus medium。状態: レビュー前。ブランチ `t363.5-saluki-forward`、本線に入れていない）**
  - **できたこと**: 塊のまま持つ作り物のモデル（Saluki の形）が、ページの forward で動く。Python の計画 → `jobs.ts` の表 → エンジン → 塊のカーネル → スレッド、と worker が塊の変換を頼んで保存する所まで。一覧の項目は足していない（T364）。訪問者に見える文は足しても変えてもいない。
