  - **重みは広げずに GPU へ**。メモリ上の形（PQ2_0 の並びの 2 ビットと、128 個ごとの float32 のスケール）のまま置く。1 重み 0.28125 バイトで、8B の層と表は 2.3 GB（int8 に広げると 9.2 GB）。**3 値の行の n 個の重みは n / 4 バイトとスケール n / 128 個で、これは int8 の n / 4 個の重みの行と同じ並び**（値 32 バイトにスケール 1 つ）。だから `gpu.js` のバッファ・塊（`piecesOf()`）・束ねた行列（`tokensLayout()`）・GPU だけの道（`routes`）は、行のバイト数（`rowBytes()`）を入れ替えただけで動く。束ねた行列の中の始まりが 256 バイトに揃うのは、手前の行列の重みが 8192 の倍数のとき（int8 は 2048）。一覧の 3 つはどれも揃う。27B の幅（5120）も行が 8 の倍数なら揃う。
  - **形と元ネタ**: 行列積は ONNX Runtime Web の DP4A MatMulNBits（MIT、`shaders.js` に前からある）だけ。プロンプトのブロックは `dp4a()` のタイルに `ternary` の引数を足し、答えのステップは `fusedDp4aMatVec` と同じ形の `ternaryMatVec`。活性値は今までどおり別のディスパッチで int8 に量子化（`QUANTIZE`・`NORM_QUANTIZE`、グループ 32）し、重みはシェーダが読む所で 2 ビットの符号から packed int8 に戻す（`ternary_packed()`）。**戻し方は Prism ML の llama.cpp の fork の Vulkan**（`PrismML-Eng/llama.cpp@88c4bc60`、`mul_mat_vecq_funcs.glsl` の `unpack_pq2_0` と `repack4`、MIT。fork は PQ2_0 の道も持っていた。許諾文は `shaders.js` の `TERNARY_PACKED` の上）: 1 バイトの 4 つの符号を 1 語の 4 バイトの下 2 ビットへ（`(b | b << 12) & 0x000f000f`、`(b | b << 6) & 0x03030303`）。うちは 1 語の 4 バイトを `unpack4xU8` と vec4 で 1 回に。Hugging Face の space（`webml-community/ternary-bonsai-2-webgpu-kernels`）は許諾の記載が無く、読んでいない（形も取っていない）。
  - **符号の読み（−1・0・+1 に直すか、0・1・2 のまま −Σa を引くか）**: fork と CPU のカーネル（T231）は符号を 0・1・2 のまま掛けて、活性値の和を後で引く（fork は活性値の塊 q8_1 が和を持っている）。うちの GPU の活性値（`QUANTIZE`）は和を持たず、そのシェーダの文は変えられない（下の「端末の鍵」）。そこで**符号を −1・0・+1 に直して掛ける**ことにした: 16 個の重みの 1 語に足し算 1 つと xor 1 つ（バイトごとに 0x7f を足して最上位ビットを反転。0〜3 に 0x7f を足しても隣のバイトに桁上げしない）。こうすると読んだ後の行は ORT のままで、T241 の「尺度の NaN がそのまま流れる」性質も変えずに済む。
  - **内側のループ（答えのステップ、1 スレッドが 1 行の 32 個の重みを活性値のグループ 32 に掛ける）**: 符号の読み 2 つ。`unpack4xU8`・シフト 2・or 2・and 2・足し算・xor を 2 語ぶん（vec4 が 1 命令の GPU で 18 命令、スカラーに分ける GPU で 72）。`dot4I8Packed` 8 つと足し算 7 つ。変換とスケールの積と積と足し込みで 4。**合わせて約 40 命令（スカラーの GPU で約 95）**。int8 の DP4A は読み 2・dot 8・足し 7・4 の 21 命令で、読むバイトは 4 倍。**0・1・2 のまま −Σa を引く形**は、vec4 の命令が 4 つ減り（スカラーなら 16）、代わりにワークグループのメモリの読み 2 つ・足し算・引き算が増え、ベクトルを読むスレッドが和を作る仕事が増える。スカラーの GPU では命令が少なく、vec4 が 1 命令の GPU では同じくらい。**どちらが速いかは未計測**。覆す条件: `/benchmark/` に 3 値の行列 × ベクトルの行を 2 つの形で足し（下の「ベンチに要る行」）、持ち主の Android で −Σa の形が速ければ替える。
