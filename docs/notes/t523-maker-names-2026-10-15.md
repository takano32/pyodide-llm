# T.523 一覧のモデルの名前に作り手を入れる（2026-10-15）

持ち主「Underdog 入れたし LINE も入れるべきだし、gemma とかも Google 入れてもよくないか？」（範囲は「全部のモデルに入れる」）。一覧の項目の名前（`name`）の頭に作り手の名を置いた。id は変えていない（既定のモデル・覚えたモデル・`?model=` は id で読むので同じ）。

## 決め方（取りまとめ役の読み）

- 作り手は**元のモデルを作った組織**。量子化と写しの作り手（unsloth・mmnga・mmnga-o・bartowski・mradermacher・QuantFactory・TheBloke・ggml-org）は入れない。派生（後訓練・続きの訓練）は**派生を作った組織**（TinySwallow は Sakana AI、Hermes 3 は Nous Research）。
- 名は Hugging Face の組織のページ（`/api/organizations/<組織>/overview` の名）とモデルカードの言い方から、短い表記で。個人は Hugging Face の利用者の名か、その人がリポジトリで使う綴り。
- **名前がもう作り手を言うものは重ねない**: llm-jp、Shisa、Underdog、RakutenAI、Llama-3-ELYZA-JP、TinyLlama、DeepSeek-R1、Mistral。
- 名前の最後の「(thinking)」「(no thinking)」「(original)」はそのまま（`tests/format_check.py` が名前の「(thinking)」を読む）。
- 置き場: 名前は今までどおり項目と家族の関数（`builders.js` の `gemma3()`・`ternaryBonsai()` は名前を組む所に 1 か所、`thinkingAndNot()`・`miniCpm5()`・`lfm2()`・`shisaLfm2()` は呼ぶ所が渡す名前）。作り手の欄は足していない（名前の文字列のほかに読む人がいない）。
