持ち主「対応したいからタスクに分轄して採番 https://github.com/tanakh/plamo-translate-desktop」。読んだのは `main` の `3d69a116c45a8116159f1a405311a59039ec4b95`（v0.6.0、2026-11-13 の公開）の README.ja.md・docs/design.md・crates/pfml・crates/engine の models.rs・document.rs・repetition.rs。ライセンスは Apache-2.0 か MIT（利用者が選ぶ）。行を写すなら、そのファイルのコメントに元の著作権の行と許諾文の全文（方針 10）。形を取るだけなら要らない。

## 何か

PLaMo 3 Translate（0.8B・2B・8B・31B の GGUF）を手元で動かす翻訳のデスクトップアプリ（Rust・GPUI・llama.cpp）。Chrome と Edge の拡張もあり、アプリなしでは wllama（llama.cpp の wasm）で 0.8B と 2B の Q4_K_M をブラウザの中で動かす（2B の生成は Radeon 8060S の WebGPU で毎秒 48 トークンほど、Ryzen 9 9950X の CPU で 18: README の値、ここでは測っていない）。

## ここにもうあるもの

- 一覧の `hf-plamo-3-translate-{0.8b,2b,8b}-{en-ja,ja-en}`（T649: PFN の Q4_K_M の GGUF を塊のまま、語彙は原本の `tokenizer.jsonl`、greedy）。書式は `formats.ts` の `plamoTranslate(source, target)` で向きを固定した 2 項目ずつ。止まりは `plamo` の `[1, 16]`。
- 塊のカーネル（Q4_K ほか、Saluki の 10 型）と、GPU の塊の型の表 `SUPERBLOCKS`（Q2_K を含む）。

## 向こうにあって、ここに無いもの

1. **PFML3 のプロンプトを組む所**（crate `pfml`）: 公式の `chat_template.jinja` と同じ順で、`dataset` → 文脈 → 履歴の対 → 用語集（`<|plamo:index|>` と `<|plamo:item|>`）→ 入力（原文の言語は省けて、省くとモデルが見分ける）→ 出力（翻訳先の言語、`ja` のときだけ文体 `form`: `plain`・`polite`）。特殊トークンと利用者の文を別の切れ端で渡し、文の中の `<|plamo:` は特殊トークンにしない（文字列にする道は断る）。言語は 53（`ja`・`en`・`zh-hans`・`zh-hant` などの小文字の符号）と、カードに無い `ja(easy)`（やさしい日本語、向こうも試験的と言う）。
2. **止まり**: `<|plamo:tag|>` と `<|plamo:bos|>`（EOS）。ここの `[1, 16]` が同じものかは未確認。
3. **長文**（`engine::document`）: 空行で段落に分け、収まるだけ詰めて 1 つの切れ端（既定 1,024 トークン、履歴 4,096。どちらも文脈から固定の部分と余白 64 を引いた残りの 1/6 と 1/3 まで）。大きすぎる段落は「文末の改行 → 文末（`。！？．`、空白の前の `.!?`、閉じかっこは文に付ける）→ 改行 → 読点と空白 → 字数」の順で切る。前の原文と訳文を履歴として新しいものから入れる。訳文の間の区切りと先頭の空白は原文のまま写す。
   - 小さい切れ端の訳（PLaMo 3 は 8 層に 7 層が直近 2,048 トークンしか見ない）: 0.8B で 250 KB の英語の本を、5,400 トークンずつだと 11 のうち 5 がくり返しに落ち段落の半分を黙って落とした。1,024 ずつなら 57 のうち 0（向こうの実測）。
4. **くり返しの検出と立て直し**（`engine::repetition`）: 周期 128 トークンまでの各周期について「1 周期前と同じトークンが続いた長さ」をトークンごとに定数の手間で数え、64 トークン以上が 3 回以上くり返せばくり返し（プロンプトの中に正当なくり返しがあれば、線をその最長の 2 倍に上げる）。出力は切れ端のトークンの 3 倍 + 128 まで。200 トークン以上の切れ端の訳がその 1/4 未満で終われば「途中で終わった」としてくり返しと同じに扱う。立て直しは「取り消して 256 トークンずつで訳し直す → 文ごと → DRY（倍率 0.8・底 1.75・許す長さ 2）で → 最初の 1 周期の後で切り、訳文に印」。くり返した訳は履歴に入れない。
5. **DRY の標本抽出**: 4 の最後の段だけで使う（ほかでは正当なくり返しも罰するので使わない）。
6. **モデルの種類**: 31B と、ほかの量子化（Q4_0・Q3_K_M・Q2_K）。31B は Q4_K_M 19.53 GB・Q3_K_M 15.86 GB・Q2_K 12.61 GB。PFN が公表する品質の数（PFTB・SaaS・WMT24++ COMET-22・FLORES+ chrF++）を量子化なしとの差で見せる（`QUALITY` の表）。
7. **一覧の自動の更新**: 起動の時に `pfnet/<family>-<size>-GGUF` を探し、新しい大きさ・量子化・版を一覧に足す（`catalog.json`）。PFN はファイルを 2026-11-04〜08 に 4 回差し替えた（どれも chat template だけ）。
