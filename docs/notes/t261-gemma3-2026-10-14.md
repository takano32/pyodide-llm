## 形

| | 270M | 1B |
|---|---|---|
| dim・FFN の内側・層 | 640・2048・18 | 1152・6912・26 |
| head | 256 が 4 つ、鍵と値の head は 1 つ（q は 1024 幅） | 同じ |
| 局所の層（`sliding_attention`） | 18 層のうち 15（6 層ごとの 6 つ目が全位置）。config は `layer_types` で言う | 26 層のうち 22。config は `sliding_window_pattern: 6` だけ |
| 窓・RoPE の base | 512、局所 1e4・全位置 1e6 | 同じ |
| 語彙・文脈 | 262,144・32,768（ページは 4096 に切る） | 同じ |
| float32・int8・6 ビットのチェックポイント | 1,076,587,036・301,771,292・234,760,732 バイト | 4,003,738,140・1,125,257,756・875,319,836 バイト |

1 トークン: `x = 埋め込みの行 × √dim`、層ごとに `x += norm(wo attention(norm(x)))`・`x += norm(w2(gelu(w1 xn) × w3 xn))`（xn = norm(x)）、`logits = 埋め込みの表 · norm(x)`。norm は `x / √(mean(x²) + 1e-6) × (1 + w)`。q と k は head ごとに norm してから RoPE、score は `q·k / √256`。softcap は無い。

## 置き場と事実

- **ファイル**: アーキテクチャ `gemma3`。行は `token_embedding_table rms_att_weight wq wk wv wo q_norm k_norm rms_att_post_weight rms_ffn_weight w1 w2 w3 rms_ffn_post_weight rms_final_weight freq_cis_real freq_cis_imag`（分類器が別なら `wcls`）。`FORM` の鍵は足していない（`head_dim` だけ）。
- **`Layout` の欄 2 つ**: `activation`（FFN の活性化: `silu`・`gelu`。GPT-2・GPT-NeoX も `gelu`）、`local`（局所の層を持てる）。
- **options**: `local: {layers, window, rope_theta}`（局所の層・窓・その RoPE の base）、`rms_norm_eps: 1e-6`、`rope_theta: 1e6`、`head_dim: 256`、`arch: "gemma3"`。
- **計画の鍵**: `activation`、層ごとの `window`・`local`、derived の `local_cis_real`・`local_cis_imag`、テンソルの `rms_att_post_weight`・`rms_ffn_post_weight`。
- **変換器が畳むもの**: norm の 1（`("one",)`）、埋め込みの √dim（表に `("scale", √dim)`、分類器が同じ表なら最後の norm に `("scale", 1/√dim)`）、q・k と head の norm の並べ替え。GGUF は norm が 1 を足した後（`done: "one"`）、q・k は HF の並び、埋め込みはそのまま（llama.cpp は実行時に掛ける）。
- **断るもの**（家族の `check`）: `gelu_pytorch_tanh` でない活性化、attention の bias、softcap（attention・logits）、両向きの attention、層の種類が 2 つでない・数が合わない config、使えない `sliding_window`・RoPE の base、`query_pre_attn_scalar` が head の大きさでないもの（27B の 168）。RoPE の縮めは共通の断り。
