# 家族（config.json の `model_type`）を足す（変換器）

AGENTS.md の「物を足す手順」節から移した（T658、2026-11-12）。要点は AGENTS.md に。

どの手順も「触る所」と「忘れると誰が教えるか」まで書く。**教えないと書いてある所は、黙って別の動きになる**。試験の側の 2 つ目の写し（`FACTS`・`ORDER`・`KINDS` など）はわざと 2 回書いてあるもので、足したら一緒に直す。

### 家族（config.json の `model_type`）を足す（変換器）

1. `src/python/convert/families/` に `Family` を 1 つ、`__init__.py` の `FAMILIES` に 1 行。**表の順が断りの文の順**。
2. **画像や音の塔を持つまるごとのモデル**（config.json の `text_config` が言語の部分）は、言語の部分の家族の `X._replace(renamed=True, before=…text_config を読む関数…, gguf=None)` を 1 つと `FAMILIES` に 1 行（Qwen3.5・Gemma 3・Gemma 4 の `*_WHOLE`）。塔の行は名指さなければ読まれない。名前の前に立つものは家族の `prefix`（`model.language_model.` など）、`test_families.py` の `FACTS` に `renamed` の 1 行。
   **Llama と数個の数だけが違う家族は `llama.py` に `LLAMA._replace(…)`**: `check`（先に Llama の `check(config)`）、`found`、`scale`、`options`、GGUF（`gguf`、`gguf_config`、`agrees`）。**`_replace` は GGUF の名前も引き継ぐ**: 自分の名前か `gguf=None` を必ず書く。
3. 新しいレイアウトの家族は自分のモジュールに: 取り込み元（`*_sources()`）を `engine/layout.py` のそのレイアウトの行の全部に（無いと「no source for the row …」）、GGUF から読むなら `gguf_names`、**llama.cpp が値や並びを変えて書くテンソルは `gguf_marks(config)` の表**（llama.cpp の名前（層の中は `blk.<層>.` の後ろの全部: `attn_q.weight`・`ssm_a`）→ 印 `{"turned" | "split" | "tiled" | "done" | "transposed" | "axis": 値}`。印が見出しに何を書くかは `convert/gguf.py` の `MARKS`。名前を `endswith` で選ばない: `tests/test_families.py` が鍵を `gguf_names` と、印を `MARKS` と突き合わせ、`FACTS` の行の `marked` が家族ごとの印の 2 つ目の写し）、llama.cpp が独自の `rope_freqs` を書く家族はその表の作り方を `gguf_rope_freqs` に。config の正規化は `before` と `after`。**窓を見る局所の層と全位置の層の 2 種類を持つ家族**（Gemma 2・Gemma 3・Gemma 4・Spark-X2.5・PLaMo 3）は `convert/families/local.py` を呼ぶ（T640.4: 種類の名前 `SLIDING`・`FULL`、`rope_parameters` を種類ごとに読む `by_kind()`・`scaling_of()`・`without_rope()`、options の `local`（`local()`・`local_options()`）、層・窓・RoPE の底の断り `local_check()`（家族の RoPE の残りの検査は引数で、底の後に）、GGUF と突き合わせる `local_agrees()`）。種類の並びの読み方と既定の値は家族ごとに違うので家族に残す。config の数の検査は `family.py` の `finite()`・`positive()`。形の鍵は `form={"鍵": 関数}`（辞書で）。**層によって作りの違う束**は sources の変換を層の番号の関数にし、回す幅は `Family.turns(config)`。行を大きさの違う部分に切るのは `("rows", 始め, 終わり, 全部)`。**取り込み元の変換は値を変える段を持てる**（`convert/plan.py` の表 `TRANSFORMS`: `("one",)`・`("plus", c)`（T649.2: PLaMo 3 の c + w の norm）・`("scale", c)`・`("decay",)`）。`("scale", c)` と、それだけで書いた `("by", …)` は断片ごとに通る（行の `piecewise`。段の並びは全体を受ける: BitNet の `planes` → `by` は全体）。行を動かすだけの段（`permute`・`heads`・`rows`: 行の `moves_rows`）は GGUF の塊のまま残れる。**新しい変換は `TRANSFORMS` に `Transform(apply, source, moves_rows, turns_back, piecewise)` の 1 行**（値の作り方・受ける形・行を動かすだけか（塊のまま残れる）・読み手の転置を打ち消すか・断片ごとに通るか。`transformed()`・`source_shape()`・`stream.py` の `piecewise()`・`stays()` は表を引くだけ）と、`tests/test_convert.py` の `TRANSFORM_FACTS` に 2 つ目の写しの 1 行。**ほかのテンソルの 1 値を掛ける段は `("by", そのテンソルの名前)`**（T283: BitNet の行列ごとの scale。`convert/plan.py` の `resolved()` が読んだ値を段に入れる。ページの `Stream` はファイルの順に読むので、**掛ける値のテンソルが行列より前にないファイルは断る**: ビルドの `convert_weights()` はどこにあっても読む）。**表の倍率は、分類器が同じ表でも最後の norm の重みで戻せば畳める**（Gemma 3 の √dim）。
4. `tests/test_families.py` の `FACTS` に 1 行（`Facts`: 題・arch・GGUF の名前・分類器・真の性質、GGUF のある家族はその表の Hugging Face の名前の前に立つもの `prefix`・表が名前を持たない行 `unnamed`・印 `marked`）。**試験はこの 1 行だけ**（T640.5: 断りの文 2 つは `FACTS` の題から試験が組み、GGUF の家族の並びも `FACTS` から。作り物の `LLAMA._replace(title="Fake", gguf="fake")` は製品の 2 か所とこの 1 行で pytest の全部が通った）。`config.py`・`plan.py`・`gguf.py`・`conversion.py`・`beginning.py`・`stream.py` は触らない。`fixed_context`・`rotatable`・`rms_norm`・`partly` は `Family` に書かない: arch の `Layout` から読む性質（T392）。
5. forward の計算が違うなら次の「アーキテクチャ」、前分割が違うなら `convert/tokenizer.py` とエンジンの `pretokenize()`（本物の `tokenizers` と全符号位置で: `EVERY_CODE_POINT=1`、実物は `tests/tokenizer_json_check.py <フォルダ> --planes 17`）。`CharClasses` で書けない型は字の種類の表（`SparkClasses`・`TekkenClasses` の形）と、`STAGES` に「表と段の並び」の 1 行（段が 1 つの型も: T611 の `tekken`、T256 の `gpt4o`）を足し（**類の 1 字は、型が字として名指す字（`(?i)` の縮約の s・t・l など）と違う字に**）、変換器の `STAGED_PRETOKENIZERS` に 1 行（Split の後ろの段の種類も見る: 後ろの ByteLevel が切り直さないこと）。GGUF の前分割の名前は、実物の GGUF の語彙と merges を原本と突き合わせてから `GGUF_PRETOKENIZERS` に。
6. 今あるモデルの変換が変わらないことを `tests/conversions_compare.py` で（変わるなら `CONVERTER` の回に）。**options に載せるのは既定と違うときだけ**。実物は `reference_llama.py` の形で transformers と比べ、通してはいけない壊し方を同じ道で入れる。
